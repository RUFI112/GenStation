# Инструкция по установке и настройке GenStation

Подробное пошаговое руководство по развёртыванию навыка для Яндекс Алисы на базе Vercel, Google Gemini API и поиска Serper. Навык работает полностью без сервера на бесплатном тарифе Vercel.

## Шаг 1. Получение API-ключей

Для работы навыка требуются два ключа (один обязательный, второй рекомендуемый):

### 1. Google Gemini API Key *(Обязательно)*
1. Перейдите в [Google AI Studio](https://aistudio.google.com/).
2. Авторизуйтесь с помощью учетной записи Google.
3. Нажмите **Get API key** → **Create API key**.
4. Скопируйте полученный ключ.

### 2. Serper API Key *(Рекомендуется для веб-поиска)*
1. Зарегистрируйтесь на сайте [serper.dev](https://serper.dev) (предоставляется 2500 бесплатных поисковых запросов).
2. Перейдите в раздел **API Key** и скопируйте токен.

## Шаг 2. Развёртывание на Vercel

### Способ 1. Напрямую по ссылке на репозиторий (Рекомендуемый)

Вам не нужно форкать проект или клонировать файлы на компьютер — достаточно указать публичную ссылку на репозиторий:

1. Откройте панель управления [Vercel Dashboard](https://vercel.com/dashboard).
2. Нажмите синюю кнопку **Add New…** → **Project**.
3. В блоке **Import Third-Party Git Repository** (или в строке импорта репозитория по URL) вставьте ссылку:
   ```text
   https://github.com/magic4n/GenStation
   ```
4. Нажмите **Continue** (или **Import**).
5. При необходимости выберите имя проекта и нажмите **Deploy**. Дождитесь завершения первичного билда.

---

### Способ 2. Через Fork (Если планируете менять код под себя)

1. Откройте страницу [https://github.com/magic4n/GenStation](https://github.com/magic4n/GenStation).
2. Нажмите кнопку **Fork** в правом верхнем углу.
3. В [Vercel Dashboard](https://vercel.com/dashboard) нажмите **Add New…** → **Project**, найдите созданную копию в списке ваших GitHub-репозиториев и нажмите **Import** → **Deploy**.

## Шаг 3. Настройка переменных окружения

После завершения развёртывания необходимо добавить полученные API-ключи:

1. В вашем проекте на Vercel откройте вкладку **Settings** → **Environment Variables**.
2. Добавьте следующие переменные (отметив окружение **Production**):

| Переменная | Обязательно | Описание | Пример значения |
| :--- | :---: | :--- | :--- |
| `GEMINI_API_KEY` | **Да** | Ключ доступа к Google Gemini API | `AIzaSy...` |
| `SERPER_API_KEY` | Нет | Ключ для актуального веб-поиска | `a8b9c...` |
| `GEMINI_MODEL` | Нет | Модель Gemini (по умолчанию: `gemini-2.5-flash`) | `gemini-2.5-flash` |

3. **Важно:** После сохранения переменных перейдите во вкладку **Deployments**, нажмите меню с тремя точками `...` напротив последнего деплоя и выберите **Redeploy**, чтобы применить новые переменные.
4. Скопируйте ваш домен из раздела **Settings** → **Domains** (например: `https://your-skill.vercel.app`).
5. Ваш итоговый адрес вебхука: `https://your-skill.vercel.app/api`.

## Шаг 4. Настройка навыка в Яндекс Диалогах

1. Перейдите в консоль [Яндекс Диалогов](https://dialogs.yandex.ru/developer).
2. Нажмите **Создать диалог** → **Навык в Алисе**.
3. Заполните основные поля:
   - **Имя навыка:** например, *«Джимини Ассистент»*.
   - **Активационные фразы:** слова, по которым навык будет запускаться голосом (например, *«запусти навык Джимини Ассистент»*).
   - **Иконка:** загрузите квадратный логотип (можно использовать файл `icon.svg` из репозитория).
4. В блоке **Backend**:
   - Выберите тип: **Webhook URL**.
   - Вставьте ваш адрес: `https://your-skill.vercel.app/api`.
5. ⚠️ **Критически важная настройка хранилища:**
   - В блоке настроек хранилища данных **снимите галочку** с пункта *«Хранить хранилище данных в навыке»* (или *«Использовать хранилище данных пользователя»*). Контекст безопасно передается через сессионное состояние (`session_state`). Включение этой галочки приводит к ошибке **Empty Response** (подробнее в [FAQ.md](./FAQ.md)).
6. Нажмите **Сохранить** внизу страницы.

## Шаг 5. Тестирование навыка

### Проверка в консоли Яндекс Диалогов:
1. Перейдите во вкладку **Тестирование** вашего навыка в Яндекс Диалогах.
2. Введите команду: *«Привет»*.
3. Навык должен ответить приветственным сообщением и предложить варианты вопросов в виде кнопок.
4. Задайте поисковый вопрос: *«Какой сегодня курс доллара?»* — навык выполнит поиск через Serper и сформирует ответ.

### Голосовая проверка на колонке или смартфоне:
1. Убедитесь, что в настройках навыка установлен доступ **«Приватный»**.
2. Войдите на вашей Яндекс Станции или в приложении Яндекс под тем же аккаунтом, на котором создан навык в консоли Диалогов.
3. Произнесите команду:
   > *«Алиса, запусти навык [ваше активационное имя]»*
4. После ответа навыка ведите диалог обычным голосом.

## Решение частых проблем

Если вы столкнулись с ошибками:
- Навык возвращает **Empty Response**;
- Алиса отвечает: *«Навык не отвечает»* (тайм-аут 4.5 сек);
- Возникает ошибка `GEMINI_KEY_REJECTED` или `User location not supported`;
- Колонка проговаривает спецсимволы Markdown вслух.

Обратитесь к подробному руководству: **[Часто задаваемые вопросы и решение проблем (FAQ.md)](./FAQ.md)**.
